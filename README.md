# 리가메디 WOS (Web Order System) 고도화

발주·재고 자동화 시스템. 병원 재고 수집 → AI 주문 제안 → 승인 → 신성아트컴 발주 → 진행 추적까지
4단계 전체를 자동화하고, 향정신성의약품 유효기간·반품·폐기·NIMS 매칭까지 관리한다.

- **범위(2026-06-16 확정)**: 기존 **리가메디닷컴 WOS(신성아트컴 제작) 유지** + **카페24 "산출 사이트" 고도화** — 현재고 파일 업로드 → 안전재고 차이 산출(제안 발주량)이 핵심.
- **리가메디 ERP = SIMS(신성)**: 발주·매출·재고·마약류(NIMS 연계 API)·KPIS 신고 처리. WOS/SIMS 모두 신성아트컴 제작 → 연동 용이.
- **파일럿 병원**: 경희채움정신과
- **플랫폼 목표 스택**: 순수 HTML/CSS/JS (카페24) + Node/PHP 백엔드 + MySQL + Claude API

## 프로토타입 화면 (현재 구현)

1. **주문 제안** — **현재고 CSV 업로드 → 안전재고 차이 산출(제안 발주량)**, ROP 공식, 향정/변동큼 배지, 안전재고·발주량 인라인 수정, 추가 발주 직접 입력, 제조사 전환·공급이슈 스위칭(+마진 기반 재스위칭 추천)
2. **승인 완료** — 5단계 타임라인, 주문 요약, 카카오 알림 안내
3. **진행 추적** — 타임라인, 택배·송장, 부분출고 배너, 출고 명세
4. **재고·유효기간** — 요약카드 5개, 위험 현황판, 완통/개봉 실사 모달(길①), 반품/양수양도/폐기 판정
5. **NIMS 매칭** — 향정 전용, 리가메디 매출보고↔병원 양수보고 사전대조, 불일치 8유형 분류·보정요청
