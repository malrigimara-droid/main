## 1️⃣ 경희채움정신과 (IT 담당) — 이지스 재고 연동

> 답에 따라 "트레이앱이 DB를 직접 읽느냐 / 내보내기 파일을 감시·파싱하느냐"가 갈림. Phase 2 설계의 분기점.

**보낼 질문**

1. 사용 중인 **이지스 제품명·버전**과 **DB 종류**(예: SQL Server / Oracle / 자체)를 알려주실 수 있나요?
2. 프로그램에서 **약품 재고를 파일로 내보내기(엑셀/CSV)** 가능한가요? 가능하면 **샘플 파일 1개**를 받을 수 있을까요?
   - 포함 항목 확인: 약품코드 · 약품명 · 현재고수량 · **lot번호** · **유통기한** · (가능하면) 일자별 사용량
3. 내보내기를 **매일 자동(스케줄)**으로 할 수 있나요, 아니면 **수동 클릭만** 가능한가요?
4. 보안상, 병원 PC에 작은 프로그램(트레이앱)을 설치해 **밤 22시에 재고만 자동 전송**하려 합니다.
   - (a) DB 직접 조회 허용 가능 / (b) 내보내기 파일만 읽기 — **둘 중 어느 쪽이 가능**한가요?
5. 그 PC의 **OS(Windows 10/11 등)**와, 외부 인터넷(HTTPS) 전송이 방화벽에서 막히는지 알려주세요.
6. 전송 데이터에 **환자 식별정보는 일절 제외**하고 약품 재고·집계만 보냅니다(PIPA 대응). 이 범위로 진행해도 될지 확인 부탁드립니다.

## 2️⃣ 신성아트컴 담당자 — 발주 수신 & 출고 회신

> #2 답으로 Phase 4(발주 전송 방식)가, "출고 회신 여부" 답으로 Phase 5(추적 자동화 가능 여부)가 결정됨.
> 만약 출고 회신 수단이 전혀 없으면 → 추적 화면은 "수동 입력" 기반으로 축소 설계.

**보낼 질문**

1. 현재 리가메디가 발주를 넣는 **방식**은 무엇인가요? (팩스 / 이메일 / 전용 포털 / 전화)
2. 발주 내역을 **CSV 또는 엑셀 파일로 보내드리면 그대로 접수** 가능한가요?
   - 가능하면 **정확한 양식**을 알려주세요: 컬럼 순서 · 약품코드 체계(표준코드/자체코드) · 수량 단위 · 인코딩(UTF-8/EUC-KR) · 헤더 유무
3. 자동 전송을 위해 **전용 접수 이메일 주소** 또는 **SFTP 업로드 경로** 중 제공 가능한 게 있나요? (**API가 있으면 가장 좋음** — 문서 요청)
4. 출고 후, **출고 결과를 회신**해 주실 수 있나요? — 약품별 출고수량 · 부분/미출고 여부 · **택배사·송장번호**
   - 회신 방식: (a) 회신 파일/이메일 / (b) 포털에서 조회 / (c) API·웹훅 / (d) 회신 없음 — 해당되는 것 표시
5. 발주~출고까지 보통 **소요 시간(리드타임)**은 며칠인가요? (안전재고 공식의 핵심 변수)

## 3️⃣ 리가메디 내부 — #3 카카오 알림톡 / #4 카페24 / #5 서버

> 이건 사장님(사용자)이 직접 확인하면 되는 항목. 외부 회신 안 기다려도 됨.

### #3 카카오 알림톡 (Phase 4 알림)
- [ ] **카카오 비즈니스 채널**(채널톡 아님, 카카오톡 채널)이 개설돼 있나? 채널 검색용 ID는?
- [ ] **알림톡 발신** 쓰려면 발신프로필 등록 + 템플릿 사전심사 필요 → 사업자등록증 준비 가능한가?
- [ ] 알림 받을 **병원 담당자 휴대폰번호**(카카오 가입번호) 확보 가능한가?
- 참고: 알림톡은 카카오 직접 신청보다 **대행사(NHN 토스트/알리고/솔라피 등) 경유**가 빠름. 비용 건당 수~십원대.

### #4 카페24 스마트앱 등록 권한
- [ ] ligamedi.mycafe24.com **관리자 계정** 로그인 가능한가?
- [ ] 카페24 **개발자센터(스마트앱)** 접근 권한이 있나? (없으면 신청 필요)
- [ ] 현재 카페24 **요금제/호스팅 플랜**은? (스마트앱·DB·외부 API 호출 가능 여부가 플랜에 따라 갈림)

### #5 api.ligamedi.com 서버 환경 (Phase 1 기반 — **가장 먼저 정해야 함**)
- [ ] ligamedi.com(메인)은 **지금 어디에 호스팅**돼 있나? (카페24 / 가비아 / 카페24외 클라우드)
- [ ] 백엔드 API 서버를 **(a) 카페24 안에 / (b) 별도 클라우드(예: AWS·Vultr 월 1~2만원)** 어디에 둘지 선호가 있나?
  - 권장: AI(Claude API)·스케줄러·DB를 자유롭게 쓰려면 **별도 소형 클라우드 1대**가 제약이 적음. 카페24는 프론트만.
- [ ] **api.ligamedi.com 서브도메인 DNS**를 추가할 권한(도메인 관리자)이 있나?
