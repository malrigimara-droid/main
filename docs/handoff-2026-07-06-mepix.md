## 1. MEPiX 정밀진단 구조 (10섹션)

1. **AI 지수 종합** — 등급(준최1~최적4) + 종합점수 + 5축 바 (GEO / AEO / SEO / 기술 / 콘텐츠)
2. **측정 대상 비즈니스** — "사이트 20페이지 살펴봄" + 업체 한 줄 요약 (신뢰 형성)
3. **AI 추천 순위** — 같은 질문에 AI가 누굴 추천했나, 경쟁사 % 랭킹 (나 = 0% 강조)
4. **AI 인용 질문 (120셀)** — 질문 24개(전환4·정보9·비교4·상황7) × 엔진 5(ChatGPT·Gemini·Claude·Perplexity·NAVER). 셀마다 등장/미등장 + "대신 추천된 곳"
5. **숫자 자세히** — AI 가시성(vs 경쟁 평균), Share of Voice, 인용 점유율, 1순위 추천율, 긍정 감성, 상황별 등장률, 순위 분포(아예 안 나옴 100%), **인용 출처 분해**
6. **네이버 AI 브리핑** — 24문항 직접 투입, 브리핑 뜬 횟수/우리 등장/우리 인용 3칸 + **실물 캡처 + 네이버가 참고한 곳**
7. **놓친 질문** — 경쟁사는 나오고 우리는 0회인 질문 전체 나열
8. **SEO 진단** — 13항목 양호/주의/오류 (llms.txt 체크 포함)
9. **AEO 진단** — 구조화 데이터 15종 체크 (FAQ·회사정보·후기평점·canonical·글쓴이·최신성·핵심답앞에·출처인용·수치통계)
10. **이번 주 할 일** — 8개, 효과●●●/노력●○○ 점수, "위에서부터 하나씩만 해도 점수 올라가요", 0/8 진행바 → 말미 무료진단 CTA

스냅샷 정직성: "전체 120셀 중 0개 등장 · **1회 실측 스냅샷**" 명시.

## 2. 훔칠 것 (우선순위순)

### A. 홈/퍼널 레벨 (앞선 분석분 포함, 통합)
1. **입력 1개 온보딩** — 도메인 하나로 시작. 타개 무료 프리뷰 = 가게명(또는 플레이스 링크) 1개 → 즉석 분석. 설문(A/B/C)은 진단 후로.
2. **결과물 예고 카드 그리드** — "무료 진단하면 받는 것 N가지", 카드 = 혜택 한 문장. 홈에 이식.
3. **등급 훅** — 등급 사다리 + "다음 등급까지 n점". 마스킹 대신 갈증 장치 (전체 무료 정책과 양립). 주간 브리핑 말미 게이지로 = 리듬 훅.
4. **예상 점수 상승폭** — 할 일 → 예상 효과. 단 §4 참조(우리는 채점까지).

### B. 리포트 레벨 (정밀진단에서 새로 확보)
5. **인용 출처 분해** — "AI는 어디를 보고 답하나": 남의 글 81% / 경쟁사 사이트 15% / 우리 0% / 커뮤니티 4% + "경쟁사는 실리는데 우리는 빠진 곳" 실명 등재 타깃 리스트. → §3 통합 논리의 근거.
6. **질문 매트릭스 문법** — 질문 유형(전환/정보/비교/상황) × 엔진, 셀 = 등장/미등장 + 대신 추천된 곳 + 실물 캡처. `keywordShareMap`과 동형 → `llmProbe` 모듈로 이식 (lib/llm-probe.ts 초안 참조).
7. **효과/노력 점수** — 처방 카드에 효과●●●/노력●○○ 2지표. "위에서부터 하나씩만".
8. **쉬운 언어 사전** — 구조화 데이터→"숨은 표시", robots→"AI·검색 로봇 안내", 결론 우선→"핵심 답을 앞에". 이 번역 수준 = 타개 카피 기준선.

## 3. 통합 논리 (전략 핵심)

**AI가 로컬 가게를 추천할 때 인용하는 근거는 결국 블로그(81%)·플레이스·카페.**
→ 타개가 이미 하는 블로그·플레이스 작업 = 곧 GEO 작업.
→ "AI 답변에 나오는 길은 동네 검색 지형을 먹는 것" — 키워드 점유 맵과 GEO가 **한 처방으로 통합**됨.
→ MEPiX는 이걸 *알려주고* 끝(도구), 타개는 *실행*이 본업(동행). 리포트 GEO 카드의 처방 문구를 이 논리로 다시 쓸 것.

## 4. 차별축 4 (MEPiX가 구조적으로 못 오는 땅)

1. **입구** — 도메인 없는 가게(플레이스 본진)는 MEPiX 입장 불가. 타개 입구 = 가게명/플레이스.
2. **실행** — 할 일 8개 전부 셀프서비스. "FAQ 구조화" 사장님이 못 함 → 동행(대행) 자리 그대로.
3. **검증** — 1회 스냅샷. 재측정→델타→**예측 채점(적중률 공개)** 루프 없음. 타개 collector엔 이미 있음(verifyPrescription·hitRateTable).
4. **사슬** — 발견에서 끝. 전환·재방문·추천(고고왁싱형 병목)은 다룰 수 없는 구조.
